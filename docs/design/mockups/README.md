# Maquetas

`demo-embebida.html` es la maqueta navegable original de la sección Demo (MAK-93, `readlater-epub`), movida aquí desde el repo de la app — es código de landing, no debía vivir con el código Python de la app.

**Referencia histórica, no el diseño actual.** La demo real se implementó en MAK-101 sobre esta maqueta casi literal, y desde entonces el registro visual de toda la landing ha cambiado (ronda 3, concepto B "tinta electrónica"). Se conserva porque documenta decisiones de composición (un único sistema de encuadre, evitar el "chrome de navegador falso") que siguen siendo válidas — el detalle está en `readlater-epub/docs/design/02-demo-embebida.md`.

Abre `demo-embebida.html` directamente en un navegador; usa la barra superior gris (arnés de QA) para alternar entre los tres estados.
